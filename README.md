# Cloud-Based Bus Pass System

A web-based bus pass and ticket booking system developed as an academic project.

## Features

- Online bus pass booking
- Route and pass type selection
- Automatic price calculation
- Prevents manual price modification in the booking form
- Unique pass ID generation
- Stores booked passes in browser local storage
- Responsive and simple user interface

## Project Structure

```text
cloud-based-bus-pass-system/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Select a route and pass type.
4. Enter passenger details.
5. Click **Generate Bus Pass**.

## Cloud Extension

The current version is a frontend prototype. For a complete cloud deployment, the application can be extended with a cloud database such as Firebase, user authentication, cloud hosting, server-side price validation, and dynamic scaling.
